# ☕ Coffee Shop Sales Dashboard (Excel Project)

An interactive Excel dashboard created using Power Query, Power Pivot, DAX, and Pivot Tables to analyze coffee shop sales performance.

---

## 📌 Objective

To analyze sales data and build a dynamic dashboard for better business insights and decision-making.

---

## 🛠 Tools Used

- Microsoft Excel  
- Power Query  
- Power Pivot  
- DAX  
- Pivot Tables  
- Charts  
- Slicers  

---

## 📐 DAX Measures

Total Sales  
= SUM(Transactions[Sales])

Total Transactions  
= DISTINCTCOUNT(Transactions[Transaction_ID])

Average Bill  
= DIVIDE([Total Sales],[Total Transactions])

---

## 📊 Features

- KPI Cards (Total Sales, Transactions, Avg Bill)
- Interactive Slicers (Month, Day)
- Auto-updating Dashboard
- Multiple Charts & Visuals
- Dynamic Data Analysis

---

## 🎛 Filters

- Month Name  
- Day Name  

All visuals are connected using Report Connections.

---

## ▶ How to Use

1. Open the Excel file  
2. Click on Refresh All  
3. Use slicers to filter data  
4. View updated dashboard  

Shortcut: Ctrl + Alt + F5
